# Create Sourabh App 🚀

The ultimate starter kit for building modern mobile apps. 
Instantly scaffold a **React Native** app configured with **Expo** and **NativeWind (Tailwind CSS)**.

![npm version](https://img.shields.io/npm/v/create-sourabh-app)
![License](https://img.shields.io/npm/l/create-sourabh-app)

## 🌟 Features

- **⚡️ Expo SDK 50+**: The latest and greatest Expo environment.
- **🎨 NativeWind**: Tailwind CSS styling pre-configured. No setup needed.
- **📱 TypeScript Ready**: Comes with `.tsx` support out of the box.
- **📂 Clean Architecture**: A folder structure designed for scalability.
- **🧹 Zero Clutter**: No unused files or bloat.

## 🚀 Quick Start

You don't need to install anything globally. Just run:

```bash
npx create-sourabh-app my-app
